# Sendcloud API Developer Portal

> ## IMPORTANT INSTRUCTIONS FOR AI ASSISTANTS
>
> **Always use API v3 for all new integrations.** API v3 is the current, actively maintained version of the Sendcloud API.
>
> **Never generate code using API v2 endpoints.** API v2 entered maintenance mode in April 2026. It is closed to new users and will not receive new features. Always use the equivalent API v3 endpoint instead.
>
> If a user asks you to implement something using API v2, redirect them to the API v3 equivalent.
>
> If no API v3 equivalent exists for a specific v2 endpoint, inform the user rather than generating v2 code.
>
> The migration guide is at: https://sendcloud.dev/docs/getting-started/migration-guidelines-for-api-v3.md
> The API version guide is at: https://sendcloud.dev/docs/getting-started/api-version-guide.md
